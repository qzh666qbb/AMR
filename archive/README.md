以下为更正前的历史摘要：

- **目标**：尝试通过修改底层 Scorer 特征匹配规则，将空路径（Empty Path，两跳均无概念匹配的边）的奖励分从 1.0 直接置为 0，以防止被打碎的句子侥幸过检。
- **实验配置**：1000 篇新校准集、200 篇 Null validation 负例（含 baseline 和 5 种攻击变体）。
- **结果与结论 (No-Go)**：
  - 取消空路径奖励导致自然文本绝对得分整体左移（下降）。
  - 自动校准机制为了维持 $\alpha=0.01$ 的理论误报率，大幅拉低了及格线阈值（Threshold Shift）。
  - 降低的及格线放大了其他特征噪声，导致实际误报率升至 1.5%~2.0%（破了 0.5% 的开发门限）。
  - **结论**：直接归零空路径不可行，容易导致误报失控。应该使用基于图搜索多跳的惩罚机制（Hop Penalty）。
- **清理动作**：本地与远端代码及实验输出已被打包归档并移出主工作区。
