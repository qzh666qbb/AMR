# Plan E：检测器反馈驱动的多阶段 SWAN 攻击

## 1. 研究目标

在保持段落事实、实体、数字、日期、否定、事件角色和可读性的前提下，系统评估以下五类攻击能否降低 SWAN 段落级检测性能：

1. 跨语言往返改写；
2. 整段联合改写与检测器反馈搜索；
3. AMR parser 分歧诱导；
4. 高贡献模板定向攻击；
5. 多步组合攻击。

最终结论必须以段落级结果为准。单句结果只用于候选筛选和机制分析。

## 2. 威胁模型

### 2.1 攻击者能力

- 可以访问待攻击文本；


- 可以调用 DeepSeek API 生成改写或翻译候选；
- 可以使用本地 BART AMR parser、T5 AMR-to-text、S2MATCH 和 SWAN 检测代码；
- 主实验按白盒检测器反馈设置执行，同时保留不使用 SWAN 分数的黑盒对照。

### 2.2 攻击约束

攻击结果必须满足：

- 命名实体逐字保持；
- 数字、日期和单位保持；
- 否定极性保持；
- 事件参与者与语义角色基本保持；
- 不删除或新增关键事实；
- 段落句子数原则上保持；
- 长度比例控制在 0.7–1.3；
- 无空句、重复句、截断和明显语法错误。

### 2.3 成功定义

严格有效攻击必须同时满足：

```text
SWAN z-score ≤ 2.33
AND 自动质量约束通过
AND 人工/AI辅助复核无重大错误
AND 语义保持 = yes 或经说明可接受的 partial
```

仅 z-score 下降的样本称为“检测逃逸候选”，不能直接称为有效攻击。

## 3. 数据与对照

### 3.1 正式数据

- 原始来源：SWAN RealNews formal 数据集；
- 主评估单位：完整段落；
- 开发集：30 个段落；
- pilot：100 个段落；
- 正式实验：250 个段落；
- 句子级自然子集仅用于候选生成调试。

### 3.2 对照组

- 无攻击原始 SWAN 文本；
- 普通单次英文释义；
- Plan B AMR 节点/边/子图攻击；
- Plan C modifier + argument 攻击；
- Plan D reentrancy 攻击；
- 不使用检测器反馈的随机候选选择；
- 使用检测器反馈的最低 z-score 候选选择。

## 4. E1：跨语言往返改写

### 4.1 路径

- EN → ZH → EN；
- EN → DE → EN；
- 可选：EN → FR → EN。

### 4.2 生成策略

每个段落、每条语言路径生成 2–4 个回译候选：

```text
原段落
→ 中间语言翻译
→ 英文回译
→ 实体/数字/否定检查
→ AMR 重解析
→ SWAN 检测
```

使用 DeepSeek 非思考模式：

- `thinking.type = disabled`
- `temperature = 0.1–0.3`
- 固定模型版本；
- 每个请求即时写入 JSONL；
- 12 路并发；
- 失败最多重试 3 次。

### 4.3 E1 消融

- 单次中文回译；
- 单次德文回译；
- 中文与德文候选择优；
- 不使用检测器反馈的固定候选；
- 使用检测器反馈的最低 z-score 候选。

### 4.4 E1 产物

```text
experiments/planE_e1_roundtrip/
  requests.jsonl
  candidates.json
  quality.json
  parsed_amrs.json
  detection/
  report.md
```

## 5. E2：整段联合改写与检测器反馈搜索

### 5.1 候选族

每个完整段落生成 8–16 个候选，候选覆盖：

- 主动句与被动句交替；
- 名词化与动词化；
- 关系从句与分词结构转换；
- 指代词与明确实体互换；
- 安全的事件拆分；
- 安全的事件合并；
- 多句协同改写。

### 5.2 两阶段搜索

第一阶段使用廉价规则过滤：

- 非空；
- 句子数；
- 长度比；
- 实体；
- 数字和日期；
- 否定；
- 重复率。

第二阶段只对通过候选执行：

- BART AMR 重解析；
- 核心 AMR 结构检查；
- SWAN z-score；
- 多目标排序。

### 5.3 候选选择

采用约束优化，而不是只选择最低 z-score：

```text
候选必须先通过硬质量约束；
在合格候选中选择最低 z-score；
若多个候选分数接近，优先选择语义和语言质量更高者。
```

同时保存：

- 全部候选；
- 淘汰原因；
- 最优候选；
- 次优候选；
- 未攻击成功但质量最好的候选。

### 5.4 E2 对照

- 第一个合格候选；
- 随机合格候选；
- 最低 z-score 合格候选；
- 不做整段联合、只做单句替换。

## 6. E3：AMR parser 分歧攻击

### 6.1 核心假设

语义相近的文本可能由 BART parser 产生不同 AMR。攻击目标是诱导合法解析分歧，而不是制造解析失败。

### 6.2 诱导方式

- 主动句 ↔ 被动句；
- 动词 ↔ 名词化事件；
- 关系从句 ↔ 分词短语；
- 代词 ↔ 明确实体；
- 一个事件 ↔ 两个子事件；
- 两个相邻事件 ↔ 一个复合事件。

### 6.3 分歧指标

比较原始文本 AMR 与候选重解析 AMR：

- S2MATCH；
- 核心谓词保留率；
- ARG0–ARG5 角色保留率；
- reentrancy 数量变化；
- 根节点变化；
- 子图大小变化；
- SWAN 模板命中变化。

### 6.4 分歧筛选原则

优先保留：

- 文本语义保持；
- AMR 合法；
- 核心事实保持；
- 非核心拓扑差异较大；
- SWAN 分数下降。

解析失败、空图或严重角色错配不能计为成功。

## 7. E4：高贡献模板定向攻击

### 7.1 目标

分析 SWAN z-score 由哪些 AMR 模板匹配贡献，定位高贡献的概念、角色和子图。

### 7.2 贡献估计

对每个段落执行 leave-one-component-out：

```text
完整 AMR 得分
减去某节点/边/子图后的模拟得分
→ 该组件的边际贡献
```

若检测实现不支持直接删除组件，则使用：

- `machine_amr_matches.json` 中的命中频率；
- 模板匹配次数；
- 模板对 z-score 的边际影响；
- 候选变换前后命中差。

### 7.3 定向算子

只攻击排名最高的 1–3 个贡献组件：

- 同义谓词框架与角色同步改写；
- 高贡献 relation 的安全反向表达；
- 高贡献 modifier 子图的等价重组；
- 高贡献 reentrancy 的拆分/合并；
- 事件名词化或动词化。

### 7.4 E4 消融

- 随机组件攻击；
- 低贡献组件攻击；
- 最高贡献组件攻击；
- 最高 3 个贡献组件组合攻击。

## 8. E5：多步组合攻击

### 8.1 推荐流水线

```text
原始段落
→ 整段句法联合改写
→ 中文/德文往返候选
→ BART AMR 重解析
→ parser 分歧分析
→ 高贡献子图定向改写
→ AMR-to-text
→ 再重解析
→ 质量过滤
→ SWAN 排序
```

### 8.2 搜索预算

开发阶段每段最多：

- 4 个联合改写候选；
- 每个候选 2 条语言路径；
- 每条路径最多 2 个定向 AMR 候选；
- 理论上限 16 个最终候选。

正式阶段先使用开发集确定的最优配置，避免对测试集无限搜索。

### 8.3 防止不公平过拟合

- 开发集用于选择算子和超参数；
- pilot 用于验证方向；
- 正式 250 样本只运行冻结配置；
- 同时报告查询次数和每段候选预算；
- 报告不使用 SWAN 反馈的黑盒版本。

## 9. 质量评价

### 9.1 自动硬约束

- 实体逐字保持；
- 数字、日期、单位保持；
- 否定保持；
- 句子数保持；
- 长度比 0.7–1.3；
- 无重复和空句。

### 9.2 自动语义指标

- 双向 NLI；
- embedding 相似度；
- S2MATCH；
- 核心事件与角色 F1；
- parser 重解析成功率。

### 9.3 人工/AI辅助复核

评分字段：

- 语言质量 1–5；
- 语义保持 yes / partial / no；
- major error yes / no；
- 错误类型；
- 备注。

最终论文应透明标注 AI 辅助、用户确认或独立人工评审的来源。

## 10. 评价指标

### 检测效果

- AUROC；
- TPR@1% FPR；
- TPR@5% FPR；
- 平均和中位 z-score；
- `z≤2.33` 比例；
- 相对原文 z-score 降幅。

### 攻击效果

- 候选生成成功率；
- 质量通过率；
- 检测逃逸候选率；
- 严格有效攻击率；
- 平均 API 查询数；
- 每个成功样本的查询成本。

### 统计

- bootstrap 95% CI；
- 配对 z-score 检验；
- McNemar 或配对比例检验；
- 多方法比较时做多重检验校正。

## 11. 分阶段执行顺序

### Phase A：30 段开发集

1. E1 中文/德文往返；
2. E2 每段 8 个联合候选；
3. E3 parser 分歧分析；
4. E4 高贡献模板定位；
5. E5 最多 16 个组合候选。

### Phase B：100 段 pilot

仅保留开发集上：

- 质量通过率 ≥ 60%；
- 严格有效攻击率 ≥ 10%；
- AUROC 下降 ≥ 0.03；
- 无明显重大错误增长。

### Phase C：250 段正式实验

- 冻结模型、prompt、阈值、候选预算和随机种子；
- 不在正式集继续调参；
- 完整保存中间产物；
- 完成统计检验与人工抽查。

## 12. 停止条件

满足任一条件即停止扩大该路线：

- 开发集质量通过率低于 40%；
- 严格有效攻击率不高于现有 Plan C 的约 4%；
- AUROC 改善小于 0.01；
- 主要低分样本来自实体、角色或事实损坏；
- 解析失败被误当作攻击成功。

## 13. 成功门槛

Plan E 只有同时达到以下条件，才可作为“有效攻击方法”报告：

- 100 或 250 个段落上严格有效攻击率 ≥ 10%；
- 质量通过率 ≥ 70%；
- AUROC 相对原始基线下降 ≥ 0.03；
- bootstrap 95% CI 支持真实改善；
- 人工复核 major error 率可接受；
- 效果不依赖无限查询或测试集调参。
