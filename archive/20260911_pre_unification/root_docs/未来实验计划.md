# AMR-SWAN 未来实验计划

## 1. 研究基础与下一阶段目标

现有实验已经完成从固定规则、单一 AMR 图算子到整段多候选检测器反馈搜索、质量感知选优和自适应补救的演进。当前主要结果包括：

- 原始 SWAN 基线 AUROC 为 0.985，TPR@1% FPR 为 89.2%；
- E2 正式实验在 250 个 RealNews 段落、每段 4 个候选的设置下，选优后 249/250 个段落低于 `z=2.33`；
- 攻击后 AUROC 降至 0.728，TPR@1% FPR 降至 6.6%；
- 质量感知选优得到 191/250 个质量合格且成功规避的段落，即 76.4%；
- 自适应补救后累计得到 218/250 个质量约束成功样本，即 87.2%。

下一阶段不再以单纯压低 z-score 为主要目标，而围绕四个问题展开：

1. **加固结论**：E2 的收益究竟来自多候选、提示词、检测反馈还是质量感知选择？
2. **深挖机制**：SWAN 为什么对句界、谓词包装和段落级搜索敏感？
3. **拓展边界**：攻击能否迁移到不同模型、数据集、解析器和反馈权限？
4. **反向防御**：能否根据攻击机制设计并验证有效防御？

## 2. 统一实验协议

后续正式实验应先冻结以下内容：

- 数据集划分、样本 ID 和基线文本；
- SWAN 代码、AMR parser、模板库和检测参数；
- 生成模型名称、版本、温度、最大输出长度和调用日期；
- 提示词版本及候选数量；
- `z≤2.33` 的检测逃逸标准；
- 质量评价表、评审流程和分歧处理方法；
- 随机种子、API 调用预算和失败重试规则。

避免在正式测试集上反复修改提示词。建议将现有样本划分为开发集和冻结测试集，所有新策略先在开发集确定，再在冻结测试集一次性运行。

### 2.1 核心指标

每项实验至少报告：

- 平均和中位 z-score；
- 平均 z-score 降幅；
- `z≤2.33` 的检测逃逸率；
- AUROC；
- TPR@1% FPR 和 TPR@5% FPR；
- 人工质量通过率；
- Valid ASR：人工质量合格且成功规避的样本比例；
- AMR 成功解析率；
- API 请求数、token 数、运行时间和估算成本；
- 95% 置信区间及适当的配对显著性检验。

### 2.2 人工质量评价

人工评价应尽量采用双人盲评。评审者不应看到 SWAN 分数、攻击是否成功或攻击方法名称。评价项目包括：

- 核心语义保持；
- 实体、数字、时间和地点保持；
- 否定、模态和归因保持；
- 事件主体、客体和关系保持；
- 是否新增或遗漏事实；
- 文本自然度与可读性；
- 整体是否可作为有效攻击文本。

报告原始一致率、Cohen's kappa 或 Krippendorff's alpha，以及分歧仲裁后的最终结果。自动语义指标只能作为辅助，不能替代人工结论。

## 3. 第一优先级：核心结论消融

### 3.1 候选数量消融

#### 研究问题

E2 的提升是否只是依靠增加候选数量？4 个候选是否具有合理的成本收益比？

#### 实验设计

测试每段候选数 `K=1/2/4/8/16`。对每个段落一次性生成 16 个候选，较小 K 使用固定候选池的子集，并对候选顺序进行重复抽样，减少不同 API 调用造成的随机差异。

其他条件保持不变：

- 相同模型和提示词；
- 相同生成参数；
- 相同质量评价；
- 相同 SWAN 检测设置；
- 相同候选选择规则。

#### 主要产出

- 候选数—检测逃逸率曲线；
- 候选数—Valid ASR 曲线；
- 候选数—AUROC/TPR 曲线；
- 候选数—成本与运行时间曲线；
- 每增加一个候选带来的边际收益。

不得预设 4 个候选已经达到收益上限，应由实验确定拐点。

### 3.2 选择与反馈组件消融

#### 研究问题

多候选生成、检测器反馈、质量优先和自适应补救各自贡献多少？

#### 实验分组

| 组别 | 候选数 | 选择方式 | 质量优先 | 自适应补救 |
|---|---:|---|---|---|
| A | 1 | 唯一候选 | 否 | 否 |
| B | 4 | 随机选择 | 否 | 否 |
| C | 4 | 仅按质量选择 | 是 | 否 |
| D | 4 | 选择最低 z | 否 | 否 |
| E | 4 | 先质量过滤，再选最低 z | 是 | 否 |
| F | 4+4 | 质量感知选择 | 是 | 是 |

采用配对设计，所有组使用相同段落和共享候选池。重点比较 D-B、E-D 和 F-E，分别估计检测反馈、质量感知和自适应补救的增量贡献。

### 3.3 攻击提示组件消融

#### 实验分组

- 纯整段同义改写；
- 去掉句界拆分/合并指令；
- 去掉谓词包装和名词化指令；
- 去掉论元与语义角色变化指令；
- 去掉指代和共指变化指令；
- 完整 E2 提示词。

所有组固定为每段 4 个候选，并分别测试随机选择和检测器选优。

大模型可能不严格遵守组件限制，因此必须事后记录实际结构变化：句子数变化、谓词变化率、ARG 角色变化率、共指变化率、AMR 图规模和图编辑距离。结论应基于实际输出差异，而不只是提示词名称。

### 3.4 提示词强度消融

设置三档提示：

- **弱提示**：仅要求同义改写并保留原意；
- **中提示**：要求改变句式和句界，但不提 AMR 或水印；
- **强提示**：完整 E2 指令，包含谓词包装、论元、句界和指代策略。

比较搜索先验与检测反馈各自的作用。除检测指标外，还应报告编辑距离、长度变化、句数变化和人工质量，避免将“改动更大”误解释为“提示先验更有效”。

### 3.5 段落长度与复杂度分层

按句子数将段落分为 2–3、4–6、7–10 和 10 句以上，并同时记录：

- token 长度；
- 原始 z-score；
- 实体和数字数量；
- 原始模板命中数；
- 被改写句子的比例。

除分层曲线外，使用回归模型分析：

`AttackSuccess ~ SentenceCount + OriginalZ + TokenLength + EntityCount`

目标是区分段落聚合、原始水印强度和事实复杂度的影响。

## 4. 第二优先级：靶向攻击与能力边界

### 4.1 高贡献句子靶向攻击

#### 方法

1. 对原始段落逐句计算水印匹配分和对段落统计量的贡献；
2. 按贡献排序，选择 Top-1、Top-2 或 Top-50% 句子；
3. 仅对目标句进行强改写，其余句子保持不变；
4. 对完整段落重新进行 AMR 解析和 SWAN 检测；
5. 与随机句子、低贡献句子和整段改写比较。

#### 研究目标

检验能否用更小文本改动获得相同或更高的 z-score 降幅，并提高人工质量通过率。若成功，这可形成比整段改写更精准的新攻击范式。

### 4.2 多轮自适应补救

针对剩余失败段落区分：

- **质量失败型**：加强事实、实体、数字、否定和关系约束；
- **检测失败型**：加强高贡献句子、谓词包装、句界、名词化和指代变化；
- **双重失败型**：先选择最小必要改写范围，再做受约束搜索。

第二、第三轮策略必须在开发集确定后冻结，再在新测试集运行。报告每轮累计候选数、查询预算和边际成功率，避免在同一测试集无限迭代造成过拟合。

### 4.3 多级质量约束曲线

建议设置：

- L1：可读且无明显事实错误；
- L2：实体、数字、否定、模态和核心事件关系保持；
- L3：双人人工盲评确认语义等价且文本自然。

分别报告各级质量标准下的 Valid ASR。BERTScore、NLI、AMR Smatch 等自动指标只作为辅助，并分析它们与人工结论的一致性。BLEU 不应作为严格语义保持的主要门槛。

### 4.4 AMR 图启发式搜索

将 Plan B/C/D 的固定图算子升级为候选搜索：

1. 解析原始 AMR；
2. 估计节点、边和子图对模板匹配的贡献；
3. 优先修改高贡献结构；
4. 生成多个 AMR 图候选；
5. 执行 `AMR修改 → AMR-to-text → BART重解析 → SWAN检测` 完整闭环；
6. 在质量合格候选中选最低 z。

不能只优化修改后 AMR 的 S2MATCH，因为 AMR-to-text 和重新解析可能恢复或改变图结构。

## 5. 第三优先级：攻击机制与可解释性

### 5.1 水印贡献归因

在句子级进行删除或替换分析，测量每句话对段落 z-score 的贡献；在 AMR 层记录各子图与50模板库的最大匹配分、命中次数和匹配结构。

验证以下假设：

- 成功攻击是否集中改变了高贡献句子；
- z-score 下降是否与模板命中减少相关；
- 哪些谓词、ARG 角色、modifier 或 reentrancy 最关键；
- 原始 z-score 越高的样本是否越难攻击。

### 5.2 句界攻击机制拆解

设计四组控制：

| 组别 | 词义改写 | 句界变化 | 重新解析 |
|---|---|---|---|
| 原始对照 | 否 | 否 | 是 |
| 仅重新切句 | 最小 | 是 | 是 |
| 改写但保持句数 | 是 | 否 | 是 |
| 改写并改变句数 | 是 | 是 | 是 |

分别分析：

1. 句界改变是否破坏单句 AMR 模板匹配；
2. 句子数量改变是否影响段落统计聚合；
3. 长句是否降低 AMR parser 的解析稳定性。

报告每句模板分数、命中模板数、AMR 节点/边数量、parser警告和聚合前后的统计量。

### 5.3 解析噪声与语义变化分解

对原文和攻击文计算：

- 人工语义判断；
- 实体、数字、否定和论元一致性；
- 自动 NLI 或语义相似度；
- AMR Smatch；
- AMR 图规模和 parser 异常。

重点识别“人工语义保持但 AMR 和检测分显著变化”的样本。Smatch 不能单独作为语义正确性的证明。

### 5.4 失败案例聚类

将失败样本划分为：

- 语义或事实失败；
- 可读性失败；
- AMR 解析失败；
- 质量合格但检测未逃逸；
- 原始水印过强；
- 改写空间不足。

分析失败与段落长度、原始 z、实体密度、句法复杂度和模板命中结构的关系，为后续攻击和防御提供依据。

## 6. 第四优先级：泛化与威胁模型

### 6.1 跨生成模型

选择至少一个不同模型家族，保持数据、提示目标、候选预算、SWAN设置和人工评价一致。比较模型间的逃逸率、Valid ASR、成本和失败类型。

### 6.2 跨数据集与领域

至少增加一个非 RealNews 数据集，并覆盖不同长度或体裁，例如百科、学术摘要、对话或技术文本。所有领域应重新建立未攻击基线，再进行攻击比较。

### 6.3 跨 AMR parser

使用第二个 AMR parser 重复检测和攻击。每个 parser 必须在人类校准集上重新确定检测分布和阈值，不能直接沿用原 parser 的 `z=2.33`。

该实验用于区分：

- 特定 BART parser 的解析脆弱性；
- SWAN 模板匹配机制的普遍脆弱性；
- 攻击在 parser 间的迁移能力。

### 6.4 三种攻击权限

明确比较：

1. **无反馈迁移攻击**：攻击者看不到检测结果；
2. **分数反馈黑盒攻击**：攻击者可获取连续 z-score；
3. **二值反馈黑盒攻击**：攻击者只能获得是否检测到水印。

当前 E2 更准确地属于基于分数反馈的黑盒攻击，而不是默认意义上的完全白盒攻击。二值反馈可先使用拒绝采样、分层提示迭代或进化搜索，不必立即使用复杂强化学习。

## 7. 防御实验

根据机制分析选择2–3个轻量防御原型：

### 7.1 多粒度检测

同时在单句、相邻双句和整段上进行解析与模板匹配，缓解句子拆分和合并攻击。

### 7.2 多解析或多切分集成

对同一文本使用不同句界切分或多个 AMR parser，聚合多个检测结果，降低单一解析路径的脆弱性。

### 7.3 模板与统计聚合改进

测试跨句模板、更多重入结构模板，以及不同聚合规则。中位数、截断均值或最大贡献聚合都只能作为待验证假设，不能预设优于原方法。

### 7.4 防御评价

每项防御必须同时报告：

- 未攻击文本上的 AUROC 和 TPR；
- 人类文本误报率；
- E2、靶向攻击和二值反馈攻击下的恢复程度；
- 攻击者知道防御后重新适配的结果；
- 额外计算与解析成本。

## 8. 推荐执行顺序与里程碑

### 里程碑 A：核心结论加固

1. 冻结协议并整理人工评审记录；
2. 完成候选数消融；
3. 完成随机选择、检测反馈、质量优先和自适应补救消融；
4. 完成段落长度与复杂度分析；
5. 形成主实验消融表和成本曲线。

### 里程碑 B：形成精准攻击

1. 实现句子贡献度计算；
2. 完成 Top-1/Top-2 靶向攻击；
3. 与随机句子、低贡献句子和整段攻击对照；
4. 完成多级人工质量评价；
5. 判断靶向攻击能否成为新的主方法。

### 里程碑 C：解释攻击机制

1. 完成句界机制拆解；
2. 完成 AMR 模板贡献归因；
3. 分解解析噪声与真实语义变化；
4. 建立失败案例分类和可视化。

### 里程碑 D：验证泛化并测试防御

1. 第二生成模型；
2. 第二数据集或领域；
3. 第二 AMR parser；
4. 二值反馈攻击；
5. 多粒度或多解析防御原型。

## 9. 停止条件与结论边界

出现以下情况时应停止继续扩大攻击生成，转向分析或如实报告负结果：

- 增加候选数后 Valid ASR 的边际收益接近零；
- 检测分继续下降，但人工质量通过率持续下降；
- 新策略只在开发集有效，冻结测试集无稳定收益；
- 攻击主要依赖 parser 失败或明显语义损坏；
- API 查询成本显著增加，但成功率提升很小；
- E3 或复杂图搜索不能显著超过更简单的 E2。

论文结论应明确区分：

- 检测规避率；
- 人工质量通过率；
- 最终 Valid ASR；
- 自动指标结果；
- 分数反馈、二值反馈或无反馈威胁模型；
- RealNews 内部结果与跨领域泛化结果。

## 10. 预期最终论文结构

完成上述实验后，论文可以围绕以下主线组织：

1. 可信复现 SWAN 基线；
2. 固定规则和 AMR 图算子的局限；
3. 句界与段落聚合脆弱性；
4. 质量感知的整段多候选分数反馈攻击；
5. 候选预算、反馈、提示组件和质量选择消融；
6. 高贡献句子靶向攻击及机制解释；
7. 跨模型、跨数据和跨 parser 泛化；
8. 多粒度检测防御及自适应攻防结果。

最核心的科学问题应从“能否找到低 z-score 文本”提升为：

> 在有限查询预算和严格人工语义约束下，AMR 水印检测器的解析、模板匹配与段落聚合链条是否存在可稳定利用、可迁移且可解释的结构性脆弱性？
