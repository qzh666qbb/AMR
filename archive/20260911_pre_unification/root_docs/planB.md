# AMR 结构级语义水印攻击：Plan B

## 0. 计划定位

本计划恢复原始研究目标：攻击 SWAN 这类基于 AMR 模板匹配的语义水印。
现有 E1–E5 结果证明了 SWAN 的句子边界/段落聚合脆弱性，但尚未完成真正
的 AMR 图层攻击。因此 Plan B 不把已有文本改写结果冒充为 AMR 图攻击，
而是将其固定为对照实验和机制诊断。

## 1. 核心研究问题

在保持语义、事实和文本质量的约束下，直接在 AMR 图层进行合法结构变换，
能否降低 SWAN 的模板匹配分数并逃逸段落级检测？

### 可检验假设

- H1：部分语义等价的 AMR 图变换经过 AMR-to-text 和重新解析闭环后仍可保留。
- H2：保留语义的图层变换能够降低 SWAN 的句级命中率或段落 z-score。
- H3：AMR 图层攻击在相同候选预算和质量约束下，至少在某些变换族上优于无 AMR 的文本改写。
- H4：收益可能依赖目标 parser 或模板库；迁移性必须单独测量。

不预设 95% 以上逃逸率，也不预设 AMR 攻击一定优于句界攻击。

## 2. 已有证据与固定对照

### 已完成

- SWAN RealNews baseline：250 段，AUC 0.985，判定为 verified_close
- E1：AMR 变量重命名和规范化保持不变；发现序列化格式敏感性
- E2：50 段 pilot，句界 Valid ASR 34%，AMR 提示改写 24%
- E3：223 段主比较，句界和 AMR 提示改写均降低检测分数
- E4：50 对严格有/无 AMR 消融，差异不显著
- E5：25-template 子集迁移检查完成

### 固定对照组

1. 无攻击 baseline
2. 普通文本复述
3. 句子拆分/合并
4. 无 AMR 的结构改写
5. 真正的 AMR 图层攻击

## 3. 真正攻击接口

攻击必须是文本输入、文本输出；AMR 是中间控制信号：

水印文本 → BART AMR parser → 结构变换器 → AMR-to-text → BART 重新解析 → 语义/事实/质量过滤 → SWAN 检测 → 接受、继续搜索或回退

直接修改 AMR 字符串、变量名、分支顺序或单行格式不算攻击成功。

## 4. 变换族

### 4.1 第一阶段：低风险变换

- 从句包装和子句边界重组
- 修饰语重新归属
- 名词化/动词化
- 控制、提升和从句表达重写
- 同一语义块的文本化顺序变化

### 4.2 暂缓变换

- 随意替换 PropBank frame
- 任意交换 ARG0/ARG1
- 仅改变 PENMAN 变量名或书写顺序
- 没有语义证明的 WordNet 同义概念替换

## 5. 评价约束

### 5.1 硬约束

- 人名、机构、地点、数字、日期保持
- 否定、模态、时间和主客体关系保持
- 双向 NLI 或等价语义判定通过
- 文本长度比例在预注册范围内
- 不允许明显重复、片段、不完整句或占位词泄漏

### 5.2 主要指标

- Valid ASR：通过全部质量约束且低于固定检测阈值的比例
- 攻击前后 paragraph z-score 下降
- AUC、TPR@1% FPR、TPR@5% FPR
- 句级命中率和最大模板 S2MATCH
- 候选数、API 调用数、AMR 解析次数、耗时和 token 成本

所有阈值先在独立校准集固定，不根据测试结果调参。

## 6. 分阶段执行计划

### B0：环境和闭环 sanity check

目标：确认 AMR → text → AMR 闭环可运行。

- 10 段
- 变量重命名、分支重排等零变化控制
- AMR-to-text 生成
- 重新解析后结构一致性检查

通过条件：零变化控制不产生检测收益；生成器和 parser 无系统性错误。

### B1：10 段图变换 smoke

- 每类变换生成固定数量候选
- 保存原 AMR、变换 AMR、生成文本、重新解析 AMR
- 统计语义过滤通过率和检测分数下降

通过条件：至少一种真正图层变换通过闭环并降低检测分数。

### B2：50 段 pilot

- 与句界攻击、无 AMR 改写进行同预算比较
- 记录失败类型和成本
- 计算 bootstrap 区间

闸门：若所有质量合格图变换均无收益，则转为 AMR parser/模板鲁棒性负结果论文；不得继续宣称高逃逸方法。

### B3：250 段主实验

- 白盒：已知模板库、parser 和检测器
- 灰盒：知道 SWAN 机制但不知道私有模板库
- 三个随机种子
- 逐样本 JSONL 和可重算汇总表

### B4：消融和迁移

- 去掉图反馈
- 去掉句界变换
- 去掉语义过滤
- 25/50/更大模板子集
- parser-specific 与跨 parser 检查

### B5：质量、防御和写作

- 至少 100 对真人或独立评审
- 失败案例分桶
- 轻量防御：规范化、parser ensemble 或跨句检测
- 最终图表、统计检验和论文证据清单

## 7. 结果解释规则

- 只有重新解析后的文本通过约束，才计为 Valid ASR。
- 逃逸但质量失败的样本单独报告，不能计入攻击成功。
- AMR 攻击只有在严格同预算比较中显示稳定增益，才能作为方法贡献。
- 若句界攻击最好，论文应诚实报告其为主要攻击，并将 AMR 结果作为机制分析。
- 若图层攻击仅在目标 parser 上有效，应标记为 parser-specific。
