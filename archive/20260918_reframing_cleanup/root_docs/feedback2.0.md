**当前证据**
根据 [当前结果](file:///Users/bytedance/AMR/CURRENT_RESULTS.md)，我们已经形成三层证据：

| 已完成工作 | 已经支持的结论 |
|---|---|

| KGW/SynthID 无反馈迁移 | 当前句界攻击没有表现出跨水印通用性 |

**最有价值的发现不是 Plan E 本身，而是“段落语义保持，不保证句级检测表示稳定”。**

但现在还不能直接把它推广为所有语义水印的共同缺陷。

**主要缺口**
- **短文本效应。** SWAN 确认集平均仅 30.9 词，单句时 z-score 上限约为 1.732，本来就不可能超过 2.33。必须说明攻击在正常长度文本上是否仍然有效。
- **跨水印比较存在混杂。** KGW/SynthID 按 160–200 个新 token 生成，与 SWAN 的长度和生成方式不同。迁移失败不能完全归因于水印类型。
- **强基线尚不完整。** SIRA-adapted 不能代替官方 SIRA，DIPPER 也没有完成等价复现；方法的新颖性仍需与相关研究核对。
- **防御证据尚未闭环。** 重分句能恢复部分检测，但需要排除“提高误报率换取检测率”的解释。

**推荐顺序**
1. **先利用已有数据，明确下一轮假设。**  
   不增加 API 调用，统计句数变化、词汇编辑比例、局部 token 序列保留程度，以及攻击前后检测分数距阈值的距离。重点回答：攻击真的改变了句界吗？跨水印失败是改动不足，还是检测统计对这些改动不敏感？这些分析作为探索，不包装成新的独立验证。

2. **优先验证 SWAN 的长度与领域泛化。**  
   在新文本上设置短、中、长三个长度层，先做小规模可行性试验，再按精度或功效要求确定正式样本量。保留普通复述、句界重组和强复述基线，统一 `K=4`、质量门和检测协议。  
   **关键判断：离开极短文本后，句界攻击是否仍有明显优势？** 如果没有，就如实定位为短文本检测边界，而不是继续追求漂亮比例。

3. **补足文献定位与可信强基线。**  
   重点核对已有工作是否研究过分句攻击、语义表示不稳定和短文本统计失效。有 GPU 后优先完成一个最相关的官方强基线，不必一次堆齐所有方法。除了成功率，还比较编辑量、质量覆盖和实际查询成本。  
   要证明的是“同等约束下有独特优势”，而不是“比普通提示强”。

4. **完成攻击与防御的验证闭环。**  
   比较原始分句、规则重分句、一个不依赖攻击者标点的确定性切分方案；对每个完整检测流程独立校准阈值。同时报告未攻击文本检测率、攻击后检测率、实际 FPR 和计算成本。  
   多种切分取最高分也必须整体校准，不能只提高检测分数就称防御有效。

5. **再决定是否扩展为通用攻击研究。**  
   泛化验证应先加入另一种真正依赖句级或语义单元的水印，检验机制能否迁移；KGW/SynthID 保留为不同机制的对照。目标反馈适配可做支线，但仅接入检测分数选优还不足以形成新的方法贡献。已经查看过的 30 条结果不能重新划一部分冒充未见测试集，需要新的最终测试数据。

**指标与执行**
主指标继续固定为**全样本无反馈 Valid ASR**，同时报告质量覆盖、基线检出率、实际 FPR、置信区间和成本。有反馈结果单列；“已检出基线上的 ASR”作为辅助指标，不再不断增加主口径。

工程上先补句级解析缓存、进度心跳和互斥任务领取，避免中断后整组重算。大规模运行前测量实际耗时，不再依据 CPU 占用猜测剩余时间。

**最终建议：下一轮先做“已有数据诊断 + 正常长度 SWAN 验证 + 强基线准备”。** 研究目标是把“攻击有效”推进到“机制清楚、边界明确、比较公平、修复经过验证”，而不是强行让同一个攻击对所有水印都有效。
