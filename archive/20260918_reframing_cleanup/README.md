# 2026-09-18 研究纠偏归档

本目录保存从工作区根目录移出的旧规划、旧反馈、旧长叙事、调试记录和演示材料。此次操作只移动文件，没有删除内容，也没有移动实验原始数据。

## 归档原因

这些文件形成于“攻击 AMR 语义”“Plan E 已完成机制证明”或旧确认协议仍有效的阶段。继续放在根目录容易被误认为当前权威入口，因此统一归档。

## 文件清单

### `root_docs/`

- `feedback.md`：历史反馈与长过程记录；
- `feedback2.0.md`：第二阶段方向反馈；
- `反思.txt`：历史研究反思；
- `任务规划.md`：已暂停的旧最终规划；
- `SWAN_RESEARCH_NARRATIVE.md`：纠偏前的长研究叙事；
- `1.txt`：历史会话/运行记录；旧脚本曾错误地把根目录同名文件当作凭据来源。

### `debug/`

- `debug-confirmation-stalled-request.md`：已结束的 stalled-request 调试记录。

### `presentations/`

- `副本ppt演示(1).pptx`：旧汇报演示稿。

## 恢复原则

归档文件可用于历史核查，但不得整体移回根目录或直接恢复旧主线。若确需恢复单个文件，必须先记录用途，并确认不会覆盖当前活动入口。
