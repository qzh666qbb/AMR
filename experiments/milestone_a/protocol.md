# Milestone A 冻结协议

## 目标

在不新增文本生成的条件下，利用正式 E2-250 的共享候选池量化候选预算、检测器反馈和质量感知选择的贡献。

## 冻结输入

- 数据：`experiments/planE_e2_joint250/quality_aware_reviews.json`
- 样本：250 个 RealNews 水印段落
- 候选：每段 4 个，共 1000 个
- 人类校准分数：`experiments/planE_e2_joint250/detection/human_z_scores.npy`
- 原始机器段落分数：正式 `formal_250x5` 基线
- 逃逸阈值：`z≤2.33`
- 随机种子：`20260817`
- 子采样重复数：1000

## 选择策略

1. 随机选择；
2. 选择最低 z；
3. 在质量合格候选中随机选择，没有合格候选时回退到全部候选；
4. 先做质量过滤，再选择最低 z，没有合格候选时回退到全部候选。

## 候选预算

现有候选池只支持严格分析 `K=1/2/3/4`。`K=8/16` 不做统计外推，必须在提示词、模型和生成参数冻结后新增 API 生成。

## 主要指标

- 平均及中位 z；
- 检测逃逸率；
- 质量通过率；
- Valid ASR；
- AUROC；
- 重复子采样的标准差与 95% 区间。

## 解释边界

- 本实验估计现有候选分布内的预算效应，不代表换模型或换提示词后的预算曲线；
- `quality_valid` 完全沿用冻结评审记录；
- 描述性分层和回归仅用于提出机制假设，不作因果解释；
- 全部 1000 个候选的 AUROC 与每段选优后 250 个候选的 AUROC 必须分开报告。
