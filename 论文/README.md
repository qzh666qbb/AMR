## 使用规则

1. 当前只按 P1/P2 两条线引用；P3/P4 只作 P1 的档案来源。
2. 不把 P3 的 variable-`N` 结果当作 fixed-`N` 定理扩展，也不把 P4 开发结果当作部署收益。
3. 不把检测端数字用于 P2 的符号读回性能；两篇共享架构不等于证据可以互相补证。
4. 历史审计清单（`report_assets/*`）保留迁移前的路径字符串，仅作历史记录，不作为当前入口。
5. 本目录只做写作与整理，不新增实验、不改写冻结终态。
