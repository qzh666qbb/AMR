本文件把当前实验产出整理成可直接并入 P1 的“结果”章节骨架。所有数字来自 `experiments/sentence_watermark_method_matrix_20261029/formal_100_20261029/`；标 ⏳ 的为占位，等 PMark attacked-null 与 AliMark raw rows 补齐。

## 本节回答的问题

1. 五个句级水印方法在**同一生成模型、同一语料**下，各自的 clean 检测能力（FPR/TPR/AUROC）是多少？
2. 当**词不变、只改句子边界或顺序**时，检测是否失效？失效是“水印被削”还是“阈值漂移”？
3. 句数 N 从固定改为可变（natural N）时，单一阈值是否还能用？

## 实验设置（一句话）

Qwen2.5-3B-Instruct（chat template 续写）生成 100 篇 C4 段落；每方法 64 候选；各方法官方编码器与官方检测器；100 篇真人 C4 段落作 human null；阈值取 null 的 95% 经验分位（严格大于），1% 档仅作指示。协议见 `formal_100_20261029/PROTOCOL.md` 与 `PROTOCOL_VARIABLE_N.md`。

PMark 的 merge/split 条件 FPR 未做：其检测每行需重新采样 64 候选，全量三条件成本过高。正文只报 clean 与 reorder，merge/split 引用 v2 的相对数时必须标注“相对数，非条件 FPR”。

配图：`figures/fig_attacked_tpr_fpr.png`（TPR 柱 + FPR 叉）、`figures/fig_attacked_dist.png`（正例/空例箱线 + 阈值线）；表：`tables/tab_attacked.tex`。

核心读法（本节的主要论点）：

- **固定密钥 / 全文聚合**方法（SwordStamp、SAMark）的空例分布在干预下几乎不动，正例的小幅下降是真实损失；换序对它们零影响（结构性质）。
- **前缀键控**方法（SemStamp、PMark）换序造成真实损失；SemStamp 换序 69%→36%，FPR 仍 5%。
- **SemStamp 的合并出现阈值漂移**：空例 FPR 从 4% 升到 12%，因此 60% 的 TPR 不能全部记作“水印保持”。
- **AliMark 换序是真实重创**：68%→14%，FPR 稳定在 5%；而合并后分数/TPR 不降（内部 RS 搜索吸收外部划分）。

可直接写的句子示例：“在固定 5% 经验阈值下，AliMark 的换序把 TPR 从 68% 降到 14%，同时空例 FPR 保持 5%，说明这是检测信号被破坏而非阈值移动；SemStamp 的合并则相反，空例 FPR 升至 12%，其 TPR 下降中包含阈值漂移成分。”

## 结果 4：失效归因（三条独立证据）

1. **SemStamp 回退率分桶**：回退 ≤30% 的 51 篇 TPR 100%，>30% 的 49 篇 37%（`figures/fig_fallback_buckets.png`）。
2. **8-bit LSH 诊断**：接受率 1.10%→1.48%，回退 32%→24%，AUROC 0.854→0.926（`figures/fig_semstamp_8bit.png`）。结论：瓶颈是编码器/文本分布导致的签名占用，不是分箱数量。
3. **PMark 合理性检查**：null 侧 0/90 次候选生成失败，p̂=0.57；正例 p̂=0.93。排除“默认通过”伪影。

## 可支持 / 不可支持

**支持**：划分依赖是**方法结构**决定的；固定密钥与聚合统计量对句序免疫，前缀键控与块序列绑定会被换序击穿；可区分“真损失”与“阈值漂移”；single-threshold 在 N∈[2,17] 内基本可迁移。

**不支持**：任何“攻击成功率”；跨模型/跨语料外推；把 5% 经验阈值当理论值；把 1% 档当结论（n=100 仅 1 个空例支撑）；把 SAMark 高 z 当作更强水印。

## 待补与占位

- PMark 的 merge/split 条件 FPR 未做（成本原因，见上）；四方法（SwordStamp / SemStamp / SAMark / AliMark）各项齐全。
- 可选：encoder 敏感度诊断（同协议只换 encoder），用于解释 SemStamp 的写入不足是否 c4-sbert 特有。

## §5 原始检测健康（正文草稿）

在讨论边界干预之前，必须先确认各检测器在未受干预的文本上本身是可用的；否则任何“掉分”都无法区分是攻击奏效还是检测器原本就不可靠。我们以 100 篇由 Qwen2.5-3B-Instruct 生成并嵌入水印的文本为正例，以 100 篇同分布真人 C4 段落为 human null，将阈值取为空例分数的 95% 经验分位，并在该阈值上报告 TPR 与实测 FPR（表 1，图 1）。五个方法全部在**同一生成模型、同一语料、每句 64 候选**下运行，差异只来自方法自身的选择规则与检测统计量。

SwordStamp 与 PMark 构成了检测能力的上界：前者在固定密钥的 green-list 上做逐单元签名，AUROC 为 0.928，在 5% 档下 TPR 为 86%；后者通过前缀重采样的软计数实现了完全分离（AUROC 1.000，TPR 100%）。两者的空例分布在图上都紧贴低分一侧，说明其检测统计量在真人文本上几乎不产生高分。我们另外对 PMark 的完美分离做了合理性检查：空例侧 90 次候选生成中没有出现失败回退，软计数均值为 0.57，正例为 0.93，排除了“候选生成失败被默认记为通过”的实现伪影。

SAMark 的读数需要谨慎解读。它的 AUROC 为 0.884，但空例的平均 z 高达 5.4，经验阈值因此被抬到 8.2，而正例均值只有 10.5——两者相距约 1.5 个标准差，5% 档 TPR 因此只有 62%。这不是“水印更弱”，而是自锚定统计量把空例一起抬高的结果；换言之，SAMark 的高 z 中混有模型自身对文本方向的一致推断，不能直接与其他方法的 z 值比较。

SemStamp 与 AliMark 处于中间位置（AUROC 0.854 与 0.874，TPR 69% 与 68%）。SemStamp 的削弱有明确的生成侧来源：约三分之一的句单元因 64 次采样内未命中 LSH 合法区而回退为未签名续写（详见 §7 的归因分析），因此其检出率被结构性稀释，而非检测规则本身失效。AliMark 的重叠主要来自正例分数分布的长尾，空例侧反而干净。

表注与图注统一写明：阈值为 human null 的 95% 经验分位（n=100），并非理论 z 阈值；1% 档在 n=100 下仅由 1 个空例支撑，只作指示；退化文档（SwordStamp 2 篇）保留在分母中。

## §3 句界影响检测（正文草稿）

句级水印的检测器并不自行切句：它接收的是上游给定的句子划分，再在“单元”层面做统计。于是存在一个不改变任何词、只改变切分方式与排列顺序的攻击面。我们把三种干预施加到正例与 human null 上，并**固定使用 clean 条件下的 5% 经验阈值**，从而把“检测分数下降”分解为两部分：正例分数下移（真实损失）与空例分数上移（阈值漂移）。

结果呈现出清晰的结构分层（表 2，图 2、图 3）。第一类是**对句序免疫**的检测器：SwordStamp 以固定密钥对每个单元独立签名，换序后逐篇的单元数、命中数与 z 值完全不变（TPR 86%、FPR 2%，与 clean 一致）；SAMark 通过全文方向推断聚合所有单元，换序同样不改变判定（62%/4%）。二者的差异出现在改变单元**数量**的干预上：合并使 SwordStamp 的 n 从 7.4 降到 6.1，TPR 降至 81%；拆分使其升至 8.1，TPR 为 82%；SAMark 在拆分时 TPR 降到 55%。这说明对这类方法，边界攻击的有效途径不是重排，而是改变单元计数与单元内的上下文长度。

第二类是**前缀键控**的检测器。SemStamp 的合法区由前文决定，换序后每个单元的前缀都变了，TPR 从 69% 掉到 36%，而空例 FPR 仍为 5%——空例分布没有移动，因此这是检测信号被破坏，不是阈值漂移。PMark 依赖在线前缀重采样，换序后正例均值从 5.38 降到 2.50，TPR 从 100% 降到 60%；其空例均值 0.84→0.85 基本不变，FPR 由 4% 升到 8%，同样以真实损失为主。

第三类是**块序列绑定**的检测器。AliMark 把消息编码为比特块并要求块序与句序一致，换序直接把 TPR 打到 14%（FPR 5%，空例未动），是全部方法中最严重的一例；但它在合并下反而略升（70%），因为其内部的随机搜索会重新切分，把外部施加的划分差异部分吸收。

SemStamp 的合并是唯一一个以**阈值漂移**为主的案例：空例 FPR 从 4% 升到 12%，正例 TPR 为 60%。也就是说，合并后的 60% 不能整体记为“水印保持”，其中一部分来自空例分布右移导致的判定宽松；报告该数字时必须同时给出 12% 的 FPR，否则会把阈值漂移误读为鲁棒性。

需要强调的边界：以上均为**单侧、无查询预算、固定文本**的干预，不能换算为攻击成功率；五种方法的 z 尺度互不可比（固定密钥、自锚定、二项、软计数）；干预只在 N∈[2,17] 的短文档上验证，长文档与自适应攻击未覆盖。

## §6 固定 N 与可变 N 的判定规则（正文草稿）

前面的结果都建立在“每篇文档取前 10 个句子单元”这一固定口径上。但真实文本的句数并不固定，认证阶段也需要一条能在所有合法划分上成立、且计算上可执行的判定规则。因此我们把同一批正例放开为**自然 N**（不截断），并把空例按配对正例的 N 截断，重新校准阈值，再与 fixed-N 的读数并排比较（表 3，图 4）。

从检测侧看，单一阈值在 N∈[2,17] 内**基本可迁移**：SwordStamp 的 TPR 从 86% 升到 90%、AUROC 持平（0.928→0.927）；SemStamp 69%→64%、AUROC 略升（0.854→0.863）；PMark 在两种口径下都是完全分离（1.000）。也就是说，暴露给攻击者的“句数”这一自由度，在短文档范围内并不会让阈值失效。

两个方向的异常值对认证规则的选择有直接含义。SAMark 随 N 增大而**变好**：N 从 10 升到 13，AUROC 从 0.884 升到 0.912，因为它的 z 随单元数放大，正例与空例的差距被同时放大——这既说明它的判定依赖文档规模，也说明其“高分”中含有句数红利，认证时不能把 z 绝对值当作水印强度。AliMark 则随 N 增大而**变差**（0.874→0.817，TPR 68%→59%）：它的原始 ABSA 分对碎片化句数敏感，尽管空例已按长度配对，阈值仍难以同时适配短、长文档。

这两点正是我们把认证规则写成 **variable-N（按文档实际单元数分层）** 而非单一 fixed-N 阈值的实证依据。此前的认证可执行性评估已经量化过两种规则的成本：fixed-N 方案在单篇文本上最多需要处理 78,642,945 个剪枝后的相邻片段对，超过 50,000,000 的硬上限，两次完整重放的保守预算上界为 86.6501 GPU 小时，超过 72 小时门限，因此**在证书评分开始之前**即停止，未产生阈值、FPR/TPR、witness 或认证率；variable-N 方案的目标层数由 46,501 修正为 47,332，既定费用模型给出的时间**下界**为 75.3111 小时，同样超过 72 小时预算，终态记为 `V4_FULL_RADIUS_READINESS_STOP`，修正后的完整计算未启动。这两个数字含义不同（86.6501 是上界、75.3111 是下界），不可拼成同一次运行，也不能用来判定哪种方案更快。本节的含义是：**检测侧允许单一阈值迁移，认证侧仍必须按 N 分层，且在现有预算下两套规则都未跑完**——这与“检测可用、认证不可执行”的记录一致。

需要说明本节不支持的推断：variable-N 只验证了“正例自然长度 + 长度配对空例”这一种配对方式，没有验证“攻击者主动制造极端 N”的情形；N 的上界只有 17，长文档未覆盖；两条规则的成本对比来自既有记录，本节未重新运行认证搜索。

## §7 失效归因与局限（正文草稿）

§3 的结论是“谁在什么干预下失效”，本节回答“为什么失效”，并界定这些结论不能外推到何处。我们给出三条独立的归因证据，它们分别指向生成侧、编码侧与实现侧。

**生成侧：回退句稀释。** SemStamp 在每个句单元上采样 64 个候选，若无一落入 LSH 合法区则回退为普通续写，该单元即为未签名单元。按文档的未签名单元占比分三档：完全没有回退的 37 篇，5% 档 TPR 为 100%（平均 z 4.49）；回退占比 1–30% 的 14 篇仍为 100%（平均 z 3.32）；回退占比超过 30% 的 49 篇骤降至 37%（平均 z 0.88）（图 5）。这条分桶曲线说明检出失败集中发生在“水印没有被写进去”的文档上：一旦未签名单元超过三成，检测统计量被稀释到接近空例水平，而不是检测规则在已签名文本上失灵。

**编码侧：签名占用而非分箱数量。** 我们把 LSH 从 3 bit 扩到 8 bit（8 bin → 256 bin）重跑同一协议：接受率仅从 1.10% 升到 1.48%，回退单元占比从 32% 降到 24%，AUROC 从 0.854 升到 0.926（图 6）。若瓶颈是 bin 太少导致候选挤在同一格，扩维应带来数量级的接受率提升；实际没有发生。因此更合理的解释是 c4-sbert 对 chat 模型 C4 续写的嵌入本身高度聚集，随机投影后仍落在少数区域——扩维改善的是“读出”（判别力与回退率），不是“写入”（签名覆盖率）。

**实现侧：排除默认通过伪影。** PMark 的完全分离（AUROC 1.000）有被实现细节污染的风险：若候选生成失败并被默认计为“通过”，空例分数会被虚假抬高。我们检查了空例侧的 90 次候选生成，失败次数为 0，软计数均值为 0.57；正例为 0.93。该伪影不存在，1.000 是真实分离。

**局限。** 第一，全部实验只用 Qwen2.5-3B-Instruct 与 C4 英文段落，换模型或换语料会同时改变生成分布与编码器行为，本节的 TPR/FPR 不可直接迁移。第二，文档长度为 10 单元（或 variable-N 下的 2–17），长文档、跨段落的划分攻击未覆盖。第三，所有阈值是 human null（n=100）的 95% 经验分位，1% 档仅由 1 个空例支撑，只能作指示；我们未报告理论 z 阈值下的结果，也不把经验阈值当作理论保证。第四，干预是单侧、固定文本、无查询预算的，不构成自适应攻击，因此不能换算为“攻击成功率”。第五，PMark 的 merge/split 条件 FPR 因检测成本未做；第六，SwordStamp 有 2 篇退化文档（模型复读输入、只产出 1 个单元），我们保留在分母中而未剔除；SemStamp 的回退率与 AliMark 对句数的敏感性都已如实报告，未做后处理筛选。

**可支持的结论与不可支持的结论。** 可以支持的是：划分依赖是**方法结构**决定的属性——固定密钥与全文聚合对句序免疫，前缀键控与块序列绑定会被换序击穿；可以用“正例下移 vs 空例上移”把损失分解为真实损失与阈值漂移；单一阈值在短文档范围内可迁移，但认证仍需按 N 分层。不能支持的是：任何形式的攻击成功率、跨模型/跨语料的一般性、把 SAMark 的高 z 当作更强水印、把 5% 经验阈值当作理论保证。
