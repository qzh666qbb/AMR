# 句级水印：六项文献对照与实验选择

核对日期：2026-10-29。服务于第一篇“句界审计与精确评估”。本文件是文献与实验设计补充，不是新增实验结果。

**判断：需要补充的是检测机制的覆盖。PMark、SAMark、AliMark、SwordStamp 分别引入多通道与前缀估计、全文方向与方差估计、序列对齐与重构搜索、固定密钥与语义短段。它们不能统一简化成 SWAN 的“合句后计数不足”。**

## 1. 六项统一对照

“句间依赖”指水印规则及检测所需状态；普通语言模型生成时读取上下文，不单独算作水印链式依赖。“保证范围”区分条件性理论、算法性质和经验结果；没有把经验抗攻击写成全扰动认证。“拆合句处理”区分检测端主动恢复与仅在攻击实验中测试。

记有效计分次数为 n、命中数为 G、零假设命中率为 p，计数型统计量记为 Z_cnt=(G−np)/√[np(1−p)]。n 不必等于自然句数：首句、提示句、短句过滤与通道数均可能改变它。具体实现必须单独核对。

| 方法／来源 | 嵌入单元 | 检测单元 | 句间依赖 | 统计量 | 拆合句处理 | 保证范围 |
|---|---|---|---|---|---|---|
| **PMark** [1] | 整句；在多个正交方向上选候选；online 按候选中位数逐通道筛选，offline 采用零中位数近似 | 重分句后的“句 × 通道”软证据；online 检测还需按观测前缀采样估计中位数 | 主设定有句序／步号种子；online 中位数依赖前缀；附录另讨论前 w 句派生种子，不能混为同一版本 | 多通道软计数的标准化**绝对偏差**；见下文 | 无 AliMark 式显式拆合重构；句序、前缀和证据单元变化均需检查 | online 在指定采样及随机种子条件下有分布不失真结论；有受限嵌入位移下的证据翻转界；offline 为近似低失真分析，均非任意拆合句证书 |
| **SAMark** [2] | 整句候选；固定方向与标志模式约束，结合候选筛选和软选择 | 各句多方向响应；全文推断方向后聚合 | 不以前句哈希更新接受区；但检测方向和方差由全文共同决定 | 对齐后的 tanh 响应均值 × √(nc)／响应标准差 | 消除前句依赖；固定单元集合下换序不变是公式推论；拆合仍会改变句向量，无显式重构 | 静态可行域性质与段落复述实验；文中明确未给出正式 distortion-free 保证；不是全重分句认证 |
| **AliMark** [3] | 每整句承载 M 位，由固定正交方向投影符号决定 | 句比特块序列，与密钥序列做自适应块对齐；再聚合多个重构结果 | 无前句哈希链；存在密钥比特流的顺序与位置同步 | 块编辑距离 BED → 归一化 BER → 零分布标准化 Z；最终取搜索中的最高分 | 原文 + 每个相邻合并 + 每句一次中点拆分；随后 ABSA 对齐；该候选集不是任意多次拆合的穷举 | 给定代价的对齐优化与经验拆合鲁棒性；不等于全部合法划分上仍可检出的保证 |
| **SwordStamp／k-SwordStamp** [4] | 语义短段；固定有效 LSH 区域／KMeans 簇；候选排序含多样性 | 先按配置切语义短段，再逐段判定固定有效区 | 检测不依赖前段来更新有效区；生成多样性排序可参考前段，须与检测状态区分 | Z_cnt；固定密钥模式从第一个单元计数，context 消融模式首单元只提供种子 | 常规句切分后，再在句内按语义变化与长度规则细分；并非取消标点句界 | 固定单元多重集下分数换序不变；已核验材料支持分段设计及经验鲁棒性，不提供本文所需的全划分证书 |
| **SemStamp** [5] | 整句语义向量的 LSH 区域；拒绝采样并留边界裕量 | 相邻句的区域转移 | 前句 LSH 签名决定当前有效区 | 有效转移计数型 z 分数 | 常规重分句；无显式拆合恢复 | 裕量设计支持局部区域稳定，鲁棒性主要由攻击实验检验；不覆盖任意句界迁移 |
| **k-SemStamp** [6] | 整句语义向量的 KMeans 簇；聚类边界裕量 | 相邻句的簇转移 | 前句簇决定下一句有效簇集合 | 有效转移计数型 z 分数 | 无显式拆合恢复 | 聚类与裕量改善语义稳定性、采样效率；非全重分句保证；k 指聚类方案，不是 k 近邻检测 |
| **SimMark** [7] | 整句；使相邻句相似度落入给定区间 | 相邻句向量相似度，可使用降维 | 一阶相邻依赖，不是离散前句哈希链 | 区间内为 1、区间外衰减的软计数，再按 p0、n 标准化 | 评估复述叠加 Drop／Merge；Merge 可插入连接词，不自动属于固定字节扰动集合；无专门恢复器 | 软计数及经验复述鲁棒性；不提供全部合法重分句证书 |
| **SWAN** [8] | 整句 AMR 结构；模板引导与匹配筛选 | 每句 AMR 与固定模板库匹配后汇总 | 固定库下无前句密钥链；依赖解析和匹配接口 | 模板命中计数型 z 分数；短文本和 NaN 路径需区分 | 原始句界影响解析与统计单元；无本文所需的盲拆合恢复 | 结构水印与经验攻击结果；本项目已有短文本接口证据，但不能外推为正常长度或所有语义水印的失效 |
| **CoheMark** [9] | 整句；模糊聚类与连贯性约束 | 按聚类规则判断有效句 | 前句隶属关系之外，还有连续同主簇事件计数与规则切换状态 | 水印有效句比例 Sv/St，与阈值比较 | 无显式拆合重构；划分改变可能同时改变簇关系和历史状态 | 连贯性和经验鲁棒性；不能未经状态展开就归入纯一阶相邻 DP |
| **PersonaMark** [10] | 整句依存结构编码；个性化哈希与候选筛选 | 每句结构哈希产生的二值证据 | 给定用户密钥时无前句哈希链；跨用户归属搜索是额外任务 | p0=1/2 的句命中 z 分数 | 不显式恢复；词汇变化下结构保留与拆合导致结构变化需分开 | 个性化归属与经验结构稳定性；没有任意结构重写、拆合句保证 |
| **IPMark：已核公开代码口径** [11] | 整句；依存结构与主谓宾上位词抽象的双路 HMAC，模型／用户分层密钥 | 句切分、短句过滤、去标点后计算两路奇偶值；按身份层及整体汇总 | 单句内容决定密钥层级；给定身份无前句链；多身份检索另计 | 两路奇偶值加权；当前 detect.py 将平均得分换算到固定 **20** 句尺度，非直接用实际 n 的 Z_cnt | 当前脚本无显式重构；拆合会改变解析、短句过滤和分层分母 | 论文主张分层归属与经验质量／鲁棒性；此处公式来自公开脚本，尚未完成论文全文与代码的逐项一致性核验 |
| **FreqMark：邻接方向** [12] | **token**；按周期信号控制候选排名 | token 排名序列上的 STFT 滑窗，用于局部定位 | 排名重建依赖语言模型前缀；周期依赖 token 位置 | 局部频谱中的目标周期信号 | 通过滑窗定位混合文本；无语义句重构；删改 token、前缀变化可能改变排名序列 | 经验检测／定位能力；它是“可句级定位的 token 水印”，不应当作又一种整句语义嵌入方法 |
| **X-Guard：待核完整检测器** [13] | 已确认整句语义空间；训练更各向同性的嵌入并使用 A²PQ 分区 | 句级检测；具体计分单位待正文核验 | **待核**，不从其他语义水印类推 | **待核**，不把二手材料的 z 公式写成已确认事实 | 当前已核官方摘要未说明专门重构步骤 | 官方摘要支持注入成功率与经验鲁棒性改进；理论条件与拆合范围待全文核验 |

## 2. 四项重点核查的含义

### PMark：版本和目标函数都影响接入

其检测汇总可写为：

$$Z_{\mathrm{P}}=\frac{\left|\sum_{t=1}^{T}\sum_{j=1}^{b}c_{t,j}-bT/2\right|}{\sqrt{bT/4}}.$$

online 的前缀重采样与 offline 的固定近似中位数需要分别登记；分布不失真结论不能直接转移给离线近似版。多通道增加的是同一句上的证据，不自动成为独立的 n 个句子。[1]

**对我们框架的推论：**即使某版本冻结后可得到局部分数，也不能把“最小化上述绝对偏差”替换成“最小化软计数”。绝对值目标不单调；只记录最小累计值的现有递推不足以直接完成这个目标。固定文本前缀有时可由跨度起点唯一确定，因此也不能反过来断言 online 必然无法局部化；应先核实步号、种子、前缀序列化和采样随机性，再证明可用的状态表示。

### SAMark：无前句链，不等于全文统计可加

设 Cij 为第 i 句与第 j 个方向的余弦响应。检测器按全文响应推断方向，再做软聚合：

$$\widehat r_j=\operatorname{sign}\!\left(\sum_i C_{ij}\right),\qquad A_{ij}=\tanh(\kappa C_{ij}\widehat r_j),\qquad Z_{\mathrm{SA}}=\frac{\overline A\sqrt{nc}}{\operatorname{sd}(A)}.$$

这里推断方向采用响应之和的符号，不能简单写成各句正负票数多数表决。方向和标准差都是文本相关量。[2]

**对我们框架的推论：**冻结原文方向或方差再攻击，相当于更换检测器。当前加性／相邻 DP 未直接覆盖这一完整统计量；后续可研究足够统计量或其他精确算法，但需另证正确性。全文推断也意味着误报应使用完整检测流程校准；这本身不是已经发现误报失控的证据。

### AliMark：内部恢复搜索必须保留

对 N 句输入，重构器含原文、N−1 个单次相邻合并、N 个单次中点拆分，共 2N 个候选。BED 以整块插入／删除及块内 Hamming 替换计价；BER 经模拟零分布标准化后，在重构／对齐搜索中取最高检测分数。[3]

**对我们框架的推论：**完整检测器的最坏情况形如“攻击划分的 min，内部恢复搜索的 max”。认证原始对齐器、关闭重构后的版本、或者一个固定候选，都不能替代认证完整 AliMark。阈值校准须包含相同候选数规则与对齐搜索，不能只校准单次 BER 检验。

### SwordStamp：语义短段仍有分段接口

本地作者代码中，semspan 先调用 NLTK／spaCy 句切分，再在句内按相邻窗口语义变化递归细分，默认配置包括 15 个内容词的长度上限与 5 词比较窗口。固定密钥检测和前句依赖消融共享代码，但计分起点不同。[4]

**对我们框架的推论：**固定有效区可提供独立跨度评分的候选实例；然而“输入任意预切跨度”的接口与“对原始文本运行真实 semspan”的接口并不相同。要保证实际扰动，必须说明所枚举划分是否覆盖真实分段结果，及每个跨度的归一化、计数是否一致。固定单元换序不变也不意味着拼回文本后重新切分仍不变。

## 3. 现有评估框架缺什么

对照依据是当前 [P1 正文](P1_句界接口审计.md) §4–5 及附录 A–B：固定 token 身份、词序与单元数的合法重分句；支持独立跨度和一阶相邻跨度评分。7,669 个枚举实例与 1,000 个退化对照检验的是现有实现。下面的“可接入”仅判断数学评分结构，**不代表已经跑通、完成校准或获得真实证书**。

| 缺口 | 文献触发点 | 应怎样补齐 |
|---|---|---|
| 检测器分类过粗 | SAMark 全文方向／方差；PMark 绝对值目标；CoheMark 历史状态 | 区分独立跨度、一阶相邻、有限状态、全文聚合、内部搜索；逐个声明支持范围，不能统一写“句级方法适用” |
| 原始文本与预切跨度混用 | SwordStamp semspan；SWAN 直接／预解析入口 | 两种接口分别登记；将分段、规范化、首句规则、短句过滤、失败处理一起冻结；检验实际文本扰动的覆盖关系 |
| 只检验 N 下降 | 现有 SWAN 5→1；不同方法实际分母不同 | 主实验增加正常长度、有效计分数守恒的边界迁移；同时记录自然句数、分段数、有效 n、通道数和归一化分母 |
| 内部搜索后阈值未统一比较 | AliMark 的 max；SAMark 的方向推断；个性化归属检索 | 对完整检测流水线独立校准；使用统一目标 FPR、各自冻结阈值；同时测被扰动的人类文本 FPR |
| 扰动集合与论文攻击错配 | SimMark Merge 可增添连接词；复述、删句、换序 | 固定字节划分、标点编辑、内容改写分别报告；换序是经验诊断，当前固定词序证书不覆盖 |
| 精确值、搜索攻击和实用运行混淆 | 新检测器复杂度不同，旧认证已在预算门停止 | 小实例用穷举核验完整检测器；大实例若只做搜索，明确标记经验最坏值，不能称认证下界 |

较自然的接入顺序是：先核验 SwordStamp 固定区／固定分段评分的可加性；复用 SemStamp／SimMark 的一阶相邻评分合同；PMark、SAMark、AliMark 单独处理完整统计量。CoheMark 可研究有限状态扩展。PersonaMark 和 IPMark 的单句证据可作为结构路线候选，但归属检索、过滤和分母仍需另核。

一个容易写反的量：若仅在攻击子集 A_search 上找到最小分数，而完整集合是 A，则 min_A D ≤ min_A_search D。搜索得到的是完整最坏分数的**上界**；它可以提供失败见证，不能用“没搜到失败”证明认证成功。

## 4. 按机制选实验代表

**核心选五种：SemStamp、PMark、SAMark、AliMark、SwordStamp。** PMark online/offline 分开报告；SwordStamp 增加同候选预算的整句消融。SWAN 保留已有结构路线证据，SimMark 复用现有相邻软分数接口作为补充。k-SemStamp／k-SwordStamp 先作分区方式对照，不占第一轮独立机制名额。

| 代表 | 独立覆盖的机制 | 最有区分度的实验／消融 | 预期能回答的问题（不是已有结果） |
|---|---|---|---|
| SemStamp | 前句决定有效区 | 固定 N 边界迁移；固定单元换序 | 计数不变时，前后句关联是否单独造成检测损失？ |
| PMark online／offline | 多通道、步号与前缀估计 | 边界迁移、单次拆合；通道数变化；两版本分别冻结 | 更多通道补偿证据数量的能力，能否抵消序号或前缀变化？ |
| SAMark | 无前句链，但全文估方向和方差 | 固定单元换序；固定 N 边界迁移；记录方向翻转和方差变化 | 去掉前句依赖后还剩多少句界敏感性，来自表示还是聚合？ |
| SwordStamp | 固定密钥与更细单元 | 同一 LSH 配置和候选预算下：context 整句 → fixed 整句 → fixed semspan；多样性排序单独消融 | 收益来自取消依赖、细分单元还是候选选择？ |
| AliMark | 序列对齐与显式恢复 | no-RS／完整 RS 分开校准；一次拆合与连续多次拆合分开 | 失同步能否被恢复？候选覆盖之外如何退化？恢复是否增加误报？ |
| SWAN、SimMark：补充 | 结构解析；连续相邻软分数 | 沿用健康且可复用接口；增加固定 N 对照 | 主结论是否跨表示类型／评分方式成立？ |

PersonaMark／IPMark 在需要验证“结构特征＋个性化归属”时进入第二批；CoheMark 用于有限状态机制扩展；X-Guard 用于研究嵌入几何与注入成功率，先补全原文与实现合同；FreqMark 放在局部定位相关工作，不直接加入整句语义水印主排名。

## 5. 最小实验协议

先做检测合同和正常长度的机制实验，再决定是否投入新的完整认证。该顺序不重启当前已经停止的 SWAN 正常长度生成或大规模认证分支。

1. **锁定完整流水线。** 每个方法保存论文版本、代码提交、模型／编码器、密钥种子、切分器、规范化、有效 n、完整统计量及无效输入返回值。PMark 冻结或按预先规定重放检测采样随机性；IPMark 当前脚本固定 20 的行为单独记录，不能直接改成标准 z 后仍称原方法。
2. **共用提示，不共用水印正文。** 各方法用自己的嵌入器生成，采用匹配的提示、模型和 token 长度区间；同一方法内做原文／攻击配对。保留作者配置，并记录候选数、总生成 token 与延迟；预算消融采用匹配预算，防止把 best-of-N 成本误作检测机制收益。
3. **独立校准和测试。** 建议先沿用本项目已有的 5% 目标 FPR，分别冻结每个完整检测器的阈值；1% 作为扩展工作点并保证足够 null 样本。校准／测试按来源隔离，报告置信区间；搜索、方向推断、身份检索都包含在校准流程内。扰动后 null 使用同一冻结阈值测试。
4. **拆开五组干预。** clean；固定单元换序；固定字节且固定有效 n 的边界迁移；改变 n 的拆合；自然文本标点编辑／连接词编辑。固定字节的接口实验只解释评分机制。原始文本实验必须重新运行分段器，并核对实际有效 n；若未守恒就转入变 n 组。复述另作扩展，不混入边界-only 结论。
5. **正常长度优先，短文本作分层。** 第一轮可先用每种方法 100 篇完整正常长度正例做机制筛查，保留全部失败生成与检测无效记录，不能仅取原始可检出的样本。该规模用于筛查，不承诺足以支持小差异的排名；正式样本量根据配对差异和置信区间目标确定。
6. **报告可解释的指标。** clean／attacked TPR、attacked-null FPR、分数与阈值间距、有效 n 和命中率、有效检测覆盖率、生成成功率与成本。对 SAMark 另报方向／方差变化；AliMark 报最佳重构类型及搜索规模；SwordStamp 报实际短段数及边界变化；PMark 报通道数与检测采样成本。
7. **最后才谈认证。** 先对很短但定义完整的实例穷举，确认官方完整检测器与适配器一致，再核验新递推；若只能搜索，报告攻击见证与预算，不报告 certified rate。没有完整求值的样本归入未完成，不归入鲁棒或不鲁棒。

最终主表应能回答：在计数保持不变时，哪些检测机制仍对句界敏感；去除前句依赖和加入恢复机制分别改变了什么；现有精确评估可以覆盖哪些完整检测器。只有“把多句合成一句后掉到阈值以下”的新增结果，不足以扩展主张范围。
