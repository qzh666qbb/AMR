当前中文标题为：

> **句级语义水印的划分依赖：条件审计与精确评估**

> 句级语义水印的鲁棒性依赖生成写入、观测单元、同步状态和完整校准；
> 本文按这些条件组织诊断，并对可覆盖的评分器求解限定划分集合中的

这篇审计的是原论文已经指出的风险，并对具体系统行为、保证范围和实现成本作可核查的评估。现有证据没有支持“提出了一个全面优于现有方法的新水印”，也不能把“句界会影响检测”或单元数上限当作原创理论。审计与负结果能否成篇，取决于是否提供了超出已有说明的、有价值的新证据。

贡献按“适用条件 → 实测行为 → 保证范围”组织：

1. **按适用条件组织完整流程评估。** 登记生成写入、观测单元、状态同步及完整校准，区分换序、变计数拆合、计数守恒迁移及原始／预切接口。它是评估合同，不将条件分类本身当作新理论。
2. **跨机制的条件性诊断证据。** SWAN 短文本 1/30 → 30/30 → 1/30 由单元数上限充分解释；五方法指定配置提供顺序与无水印判定变化的线索。SwordStamp 整句配置、校准集误报、条件分母和缺少同模型无水印对照等限制保留；正常长度计数守恒主端点仍未确认。
3. **限定划分集合的精确最坏分数。** 固定 token 身份、顺序与单元数，为独立片段和一阶相邻评分实例化并核验精确 DP。相邻评分有 7,669 个穷举对照及 1,000 个退化对照；不覆盖全部五方法的完整统计量。SemStamp 原始检测的独立 47/1000、954/1000 属于原始检测证据，真实认证仍未估计。

### 2.1a 原文复核：哪些内容已经有先例

2026-10-25针对用户的新颖性质疑，直接复核SWAN、SemStamp、SimMark、
AliMark与SwordStamp原文。本次是这些已知基线的出处核查，不扩展论文主题
或新实验范围。

| 本方案涉及的内容 | 原论文中的对应内容 | 本项目允许的定位 |
|---|---|---|
| SWAN的z统计量与单元数依赖 | [SWAN §3.3](https://arxiv.org/html/2605.04305v1#S3.SS3)已给出同一统计量；[SemStamp附录B](https://arxiv.org/html/2310.03991v2#A2)也给出句级one-proportion z-test | 原方法组成，需引用，不是本项目新定义 |
| $z_{\max}(N)=\sqrt{N(1-\lambda)/\lambda}$及$N=1$不过阈值 | 是已有公式结合$G\leq N$的直接推论；[SwordStamp §5.3](https://arxiv.org/html/2608.27666v1#S5.SS3)已明确写出固定命中率下$z$随$\sqrt{n}$增长 | 基础推导和解释性必要条件，不列为原创理论贡献；不能误说SWAN原文已逐字给出相同上限定理 |
| 拆句、合句会改变AMR结构 | [SWAN §6 Future Directions](https://arxiv.org/html/2605.04305v1#S6.SS0.SSS0.Px1)明确列为挑战，并提出paragraph/multi-sentence AMR及AMR subgraph方向 | 验证和量化已指出的风险，不能声称发现原作者未预见的攻击面；事件子图构想本身也有先例 |
| 句间编辑会破坏句级水印 | [SemStamp局限性](https://arxiv.org/html/2310.03991v2#Sx1.SS0.SSS0.Px1)承认inter-sentence攻击风险；[SimMark §4.3](https://arxiv.org/html/2502.02787v2#S4.SS3)已实验评估Paraphrase+Merge；[AliMark §2](https://arxiv.org/html/2605.29434v1#S2)与[SwordStamp §4](https://arxiv.org/html/2608.27666v1#S4)给出结构扰动分析 | 一般风险已有说明和实验；不同系统的具体机制不能互相替代 |
| 重构候选与DP对齐 | [AliMark §3.2.1–§3.2.2](https://arxiv.org/html/2605.29434v1#S3.SS2)已使用单步拆/合候选与block-edit DP；正文式(4)给出递推 | “用DP处理句界或序列”不是首创 |
| 最小分数超过阈值等价于全部合法划分检出 | 来自有限集合最小值的定义 | 证书语义，不能单独作为新定理 |
| fixed-token/fixed-`N`全合法重分句的最坏分数及edge-state DP | 本次核对的五篇原文中未找到相同威胁集、最坏分数目标及对应递推；AliMark求最有利的检测/对齐，而本框架求最坏检测分数 | 特定问题的形式化、算法实例化与实现核验；这项差异不足以证明全局新颖性或强理论贡献 |

SWAN原文明确写道：

> “multi-sentence attacks—such as splitting or merging sentences to alter AMR structure”

SwordStamp原文将公式改写为：

$$
z=\sqrt{n}\,\frac{\hat p-\gamma}{\sqrt{\gamma(1-\gamma)}}.
$$

所以，“有可证明的结论”与“有新的理论贡献”必须分开。现有材料能形成
有边界的系统审计稿件，但原创贡献仍偏薄：主要配对结果属于已预见风险的
具体实例，正常长度count-neutral机制与真实最终certificate仍缺失。
原TMLR“准备Go”是历史准备裁决，不能读成新颖性已通过、录用有保证，
或本次原文核查升级了任何实验端点。

### 2.1b 叙事主线：适用条件 → 实测行为 → 保证范围

按用户给出的基调，正文依次回答：

1. **背景与适用条件。** 句级语义水印需要充分写入，再按观测单元和同步状态读取，最后通过完整流程校准。不同原方法已处理部分结构风险，不能统一假设都依赖原始句界不变。
2. **研究问题。** 划分策略怎样影响检测保证与鲁棒曲线？哪些变化来自单元数，哪些来自跨度内容和相邻关系？校准及计算成本又怎样限制有效结论？
3. **受控审计。** 当前有短文本合并 A–B–A、五方法指定配置诊断和局部评分精确核验。五方法不替代正常长度计数守恒端点、完整方法消融或独立条件误报；其他划分策略与复述比较作为待验证问题，不冒充已完成实验。
4. **正向有效范围。** 已有数学结论是：对冻结评分器，若声明集合内的完整最坏分数超过阈值，则该集合内全部合法划分可检出。相同有序字节单元交给相同确定性检测器，分数相同。二者均不能推出“保留粗粒度句界就能稳定检出并控制FPR”。
5. **边界声明。** 深度复述、大范围重组、段落重排、长句融合可能改变token、词序或单元数，超出当前证书集合，此时原保证不能援引。句界是解码和评估的中间假设，不能据此抵挡任意强改写。

**建议直接写进论文的边界句：**

> 当改写不再满足声明的划分与评分合同，本文的检测保证不再适用。
> 超出保证范围后的实际检出率需要另行评测；本文不证明所有依赖句界的
> 语义水印在强改写下必然失效。

| 希望建立的结论 | 当前能写的程度 | 尚缺证据 |
|---|---|---|
| 合适划分在轻度攻击下维持检测并控制FPR | 研究假设，尚未建立经验有效区间 | 冻结多策略对比、独立人工质量、完整流程校准和条件特异FPR |
| 部分划分对拆句/合句更敏感 | 有一般原理与既有文献；本项目未给出策略排名 | 匹配条件下的拆/合对比，分离单元数与跨度变化 |
| 声明有限集合内全部划分可检出 | 最坏分数通过阈值时的条件性数学保证 | 最终健康真实系统上的非空证书与鲁棒曲线 |
| 强改写使保证失效 | 实际扰动越出声明集合时，原证书不适用 | 若主张实际检出失败，仍需专门攻击实验；普遍必败需更强理论 |

英文稿中将“有效区间”的精确定义写为固定阈值下的认证半径：

$$
k^\star(x;\tau)=\max\{k\in\{0,\ldots,K\}:C_k(x)>\tau\}.
$$

这一定义以完成评分且集合非空为前提。最终v18没有完成评分，所以其半径
和certified rate均为未估计；不能写成0，也不能用v17的原始TPR替代。
不同半径分别重新校准阈值后，经验TPR曲线不必单调。

### 2.3 建议正文结构

章节与[当前中文完整稿](01_句界审计与精确评估/第一篇_中文完整稿.md)一致；旧英文稿需在后续写作任务中同步。

3. **SWAN 配对实验：**短文本 A–B–A、数量上限、入口差异和未确认端点。
4. **精确评估：**固定单元数的允许集合、两类局部评分、条件保证与校准。
5. **五方法诊断：**真实配置、原始与干预比例、自然长度重校准和生成回退。
6. **算法及真实系统核验：**穷举、独立原始检测、固定与可变单元数的资源停止。

8. **讨论：**条件分母、因果与统计限制、完整检测器范围及证据缺口。
9. **结论：**条件明确的评估、诊断和有限集合求值；不把算法核验写成真实鲁棒成功。

候选标题：

> **From Semantic Templates to Recoverable Symbols: An Audit of an AMR-Based Channel**

核心问题：

> 一个指定的语义结构被写入文本后，能否由不知道目标符号的读出器在新文本和复述中稳定恢复？失败主要发生在语义实现、解析、符号判别、候选筛选还是序列还原？

### 3.3 路线A：先形成有解释力的载体审计

最接近现有数据的中心主张候选是：

> 在这套冻结 AMR 模板通道中，必要结构标记和相对序列排序均不足以保证符号身份及完整序列的可靠读回；需要逐阶段验证写入与读出是否对应同一份语义证据。

前半句已有有限数据支持，后半句目前是设计启示。要让它成为更有解释力的论文，应先完成现有[人工盲评包](../第二篇_语义消息写入与读回/02_实验/semantic_sequence_readout1/HUMAN_REVIEW.md)，核对目标语义、复述保真和盲事件对应，再按全分母分解：

| 阶段 | 必须核对的对象 | 判断依据 |
|---|---|---|
| 写入 | 文本是否真正表达目标事件、角色方向和语气 | 真人目标语义检查 |
| 复述 | 目标事件及其关系是否仍在，叙述顺序是否变化 | 真人源文—复述对照 |
| 解析 | 已确认的语义证据是否保留在AMR输出中 | 人类语义与固定parser输出逐项对照 |
| 符号判别 | 输入位置正确、语义存在时，是否读成正确类别 | 人工确认层的混淆、擦除与全分母结果 |
| 候选筛选 | 额外观察是其他真实事件、嵌套事件还是重复观察 | 全文盲事件标注 |
| 顺序还原 | 对应明确时，原序列能否唯一恢复 | 保留全部候选及并列处理的固定评价 |

不能将155/164个未匹配候选全记为错误事件，不能将人工确认成功的子集当作新的主分母。可以同时报告全样本结果和预先说明的条件分层，明确后者只用于解释。

人工材料回收将产生新的验证证据，应单独记录来源和时间，保留原报告及原 No-Go。若需增加模型调用、gold-graph干预或新对照，另立冻结协议，不回填旧批次。

这一路线的成篇条件是：得到可核查的语义真值，识别清楚至少一个失败环节，并说明结论如何超出“某套参数没调好”。如果仍只能说这24个模板在12对文本上效果不足，适合保留为技术报告或初步研究材料，独立正式论文价值有限。

### 3.4 路线B：进一步成为新水印方法论文

若目标是自己的正向方法，必须形成比“AMR→聚类符号→序列对齐”更具体的技术增量。AliMark已有秘密比特序列、重构与对齐；SWAN已有AMR模板注入。新增模块与标准算法组合本身不足以证明新颖性。

项目已有短窗、长窗、事件子图的分数级交叉注意力开发实验，但它不是
readout1的符号序列解码器，也不是词—事件—段落层次编码器；旧主工作点
没有确认它相对门控的稳定额外收益。若第二篇引入事件序列网络或层次
注意力，应先用真人证据定位写入、解析、身份与定位损失，再以同输入、
同预算和新确认数据验证模块增量，不能直接把旧融合结果迁移为读回证据。

可研究的改进方向包括：有明确身份与角色约束的载体、可验证的写入合同、叙述顺序和事件时间的分离，以及对声明编辑通道的纠错。它们都属于待论证方向，当前不宣称首次或已经有效。

一篇方法论文至少需要以下闭环：

1. **给出具体新机制。** 明确编码对象、密钥作用、解码对象与安全假设，证明它解决了当前可定位的失败，而非仅增加模型或搜索。
2. **固定合法扰动。** 明确是否覆盖复述、句子合并/拆分、事件插删和重排。如果允许任意保义叙述重排，单靠表面顺序编码没有普遍的最坏情况恢复保证；需限制通道或加入额外可识别信息。
3. **在开发之外验证写入与解码。** 新提示对之外，还需按主张评估新模板、来源和领域的泛化；使用人工语义真值，禁止读出器借用目标答案。
4. **比较有能力的基线。** 在合理匹配的模型、质量、长度和预算下比较 SWAN、AliMark，以及直接图匹配、无序统计和具备足够覆盖的 embedding 读出；现有MiniLM的类别偏好不能充当成熟方法上限。
5. **报告真正的终点。** 若主张信息恢复，报告符号错误/擦除、消息错误、top1及并列规则；若主张检测，冻结完整流程后整体重新校准，报告独立人类测试FPR与TPR。同时报告质量和成本。
6. **用新冻结协议接受失败。** 样本量由主要效应、统计单位和精度要求确定；不能边补样边选择表示，直到结果过门。

方法路线的 Go 条件是“具体的新贡献与独立完整终点都成立”。现有77.48%可以作为立项线索，不能替代该条件。

顺序、同一符号证据上的无序/有序消融及完整序列恢复。

## 4. 为什么暂不单独写第三篇认证方法论文

当前认证贡献已进入第一篇，独立拆稿存在两个问题：基本DP与校准思路不是新理论；真实最终certificate未产生。容量扩展、renderer修复、cache和compiled core优化有工程价值，但并不自动形成独立方法贡献。

第三篇最新定位希望提出与事件序列读回解耦的认证机制。这可以作为研究设想，
但目前未实现独立于原检测器的新信号，未验证两条链路的互补收益。
现有 SemStamp exact verifier 不使用 AMR 事件符号，仍依赖句向量、
LSH 与原检测评分；它保证的固定字节重划分也不覆盖轻度复述或事件改动。
文中应明确承认：本轮没有达到实用独立认证的目标，不能把算法检查通过写成
“中等强度语义攻击下已经有效”。强语义改写属于当前范围外，也没有实测
证据足以写成新机制已经被攻破。完整叙事见[失败记录](01_句界审计与精确评估/第三篇_独立认证方法_失败与边界记录.md)。

第三篇候选的完整闭环应区分原阈值下的认证与重新校准最坏分数的检测器。
现有新防御合同以fixed-byte detector-unitization集合上的exact minimum
为主统计量；它不覆盖标点修改或复述。真实证书产出后，证书引导生成还
需在相同prompt、候选池、质量门与阈值下比较first-qualified、clean-score、
合法复现的SwordStamp-style margin及exact-certificate选择。
原PLAN残留的近似选择文字应在新协议中限定为近似消融，不能冒称exact主方法。
这些待完成工作及历史门的口径见[研究闭环](../第二篇_语义消息写入与读回/01_论文文档/第二第三篇研究闭环.md)。

2026-10-25闭环核查进一步区分了请求半径和实际effective半径：
v3资源协议使用`min(请求半径, 原边界数)`，请求半径2有28篇被收窄，
半径3有155篇被收窄，主半径1未受影响。原始威胁定义允许纯边界插入，
因此该cap不能直接作为原始半径2、3全集的覆盖证明。历史Stop不变；
旧77.6152小时账本不能冒充扩大全集的预算上界。

按用户授权另立的 v4 已对齐原半径预算，修正 Python 截断和 C++ 的
`b>m0` 拒绝条件；完整 3,000 行目标层计划由46,501增加到47,332。

tokenizer/Punkt。v4终态为`V4_FULL_RADIUS_READINESS_STOP`，
新全量 profile、detector与certificate均未执行。该下界不是新实测用时，
也不能当作精确上界。v3和旧v18终态不变。
参见[v4合同与结论](../experiments/semstamp_certified_defense_v4_full_radius_profile1/CONCLUSION.md)、
[资源审计](../experiments/semstamp_certified_defense_v4_full_radius_profile1/RESOURCE_AUDIT.json)。
下一步若继续，须另立预算/优化合同并恢复SHA一致的原始输入；
本轮没有自动授权后续实验。

以后只有出现实质性增量，才重新评估独立论文，例如：

- 对当前方法不能处理的检测器或威胁集建立新的、可证明正确的保证；
- 解决明确的瓶颈，同时保持威胁集、精度和统计合同，在健康真实系统上产出有用的证书；
- 提供具有独立研究意义的理论界、算法结果或系统发现，并与已有精确方法比较。

新的证书终点可以增强研究，但不单独保证算法新颖性；新定理也需证明其问题和结论具有价值。未来延展应明确引用第一篇及复用部分，新增贡献不能再次将同一oracle、同一A–B–A或同一健康结果作为独立论文的主要新发现。
